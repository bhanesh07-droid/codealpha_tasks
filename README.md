# CodeAlpha Artificial Intelligence — All 4 Tasks

Based on the uploaded **Artificial Intelligence Tasks & Instructions — CodeAlpha** document.

The document lists four AI tasks:
1. Language Translation Tool
2. Chatbot for FAQs
3. Music Generation with AI
4. Object Detection and Tracking

The instructions say interns should complete any 2 or 3 of the four tasks. This package contains all four as requested.

## Separate ZIP files

- CodeAlpha_Task_1_Language_Translation_Tool.zip
- CodeAlpha_Task_2_FAQ_Chatbot.zip
- CodeAlpha_Task_3_AI_Music_Generation.zip
- CodeAlpha_Task_4_Object_Detection_Tracking.zip

Each ZIP contains source code, requirements, README and an explanation of the implementation.

## External dependencies

Task 1 requires a translation provider/API and credentials if Google Cloud Translation is selected.
Task 2 is self-contained.
Task 3 requires Python packages plus MIDI files; a small original seed MIDI corpus can be generated locally.
Task 4 downloads YOLO weights through Ultralytics on first use.

## Submission reminder

The CodeAlpha document also asks interns to upload source code to a GitHub repository named `CodeAlpha_ProjectName`, post a video explanation on LinkedIn with the GitHub link, and submit the completed task through the submission form.
